# bankms-py

A **Python-based multi-user banking system** that allows users to perform basic banking operations through a console interface.  
This project demonstrates file handling, authentication, and transaction management.

---

## Features

- User & Admin Login System
- Multi-user account support
- Deposit and Withdraw money
- Fund transfer between users
- Transaction history
- Interest calculation
- Loan eligibility check
- Account deletion
- Admin panel (view & delete users)

---

## Technologies Used

- Python
- File Handling
- Dictionaries
- msvcrt (for password masking)

---

## Project Structure

- `code.py` - Main program
- `bank_sample.txt` - Sample data file
- `report.pdf` - Project documentation (optional)

---
